# 오류신고 관리 시스템

## 프로젝트 소개

오류신고 관리 시스템은 사용자가 서비스 이용 중 발생한 오류를 신고하고,
관리자가 해당 오류를 확인하여 처리상태 변경 및 답변을 등록할 수 있는 웹 기반 관리 시스템입니다.

이 프로젝트는 단순 게시판 CRUD를 넘어,
회원/권한, 오류신고 접수, 관리자 처리, 상태 관리, 검색, 페이징 기능을 구현하고, 파일 첨부와 알림 기능 등 실제 서비스 확장을 고려하며
백엔드 개발의 기본 구조를 학습하고, 실제 서비스 흐름과 비슷한 구조를 직접 구현해보는 것을 목표로 합니다.

## 사용자 역할

### 일반 사용자
- 회원가입 및 로그인
- 오류신고 등록
- 본인이 작성한 오류신고 목록 조회
- 본인이 작성한 오류신고 검색
- 본인이 작성한 오류신고 상세 조회
- 답변 전 오류신고 수정
- 답변 전 오류신고 삭제
- 오류신고 목록 페이징
- 관리자 답변 확인

### 관리자
- 전체 오류신고 목록 조회
- 오류신고 목록 페이징
- 오류신고 상태별 필터리이
- 오류신고 제목/내용 검색
- 오류신고 상세 조회
- 답변 등록/수정 시 처리상태 변경
- 관리자 답변 등록 및 수정

## 1차 개발 완료 기능

### 사용자 기능
- 회원가입
- 로그인 / 로그아웃
- 오류신고 등록
- 내 오류신고 목록 조회
- 내 오류신고 상세 조회
- 관리자 답변 확인

### 관리자 기능
- 전체 오류신고 목록 조회
- 오류신고 상세 조회
- 관리자 답변 등록
- 관리자 답변 수정
- 답변 등록/수정 시 처리상태 선택

### 공통 기능
- 권한 체크
- 입력값 검증
- 본인 작성 오류신고 접근 제한

## 2차 개발 완료 기능

- 사용자 오류신고 목록 페이징
- 관리자 오류신고 목록 페이징
- 사용자 오류신고 제목/내용 검색
- 관리자 오류신고 제목/내용 검색
- 관리자 오류신고 상태별 필터링
- 답변 전 사용자 오류신고 수정
- 답변 전 사용자 오류신고 삭제

- 첨부파일 업로드 / 다운로드
- 반려 처리 및 반려 사유 관리
- 처리 이력 관리
- 이메일 알림
- 엑셀 다운로드
- 통계 대시보드
- 비밀번호 복잡도 정책 적용

- Spring Security
- Spring Data JPA
- PostgreSQL
- Gradle

### Frontend
- 1차: Thymeleaf
- 2차: React 전환 예정

## 확장 아이디어

- 오류신고 등록 시 관리자 이메일 알림 또는 문자메세지 발송
- 처리상태 변경 시 사용자 이메일 알림 또는 문자메세지 발송 
- 처리 완료된 오류신고 엑셀 다운로드
- 관리자용 통계 대시보드 추가
