# API/URL 설계서

## 1. 문서 개요

본 문서는 오류신고 관리 시스템의 현재 구현 기준 URL 설계를 정의한다.

1차 개발에서는 `Thymeleaf`를 사용하여 서버에서 HTML 화면을 렌더링하는 방식으로 구현한다.  
따라서 본 문서는 순수 REST API 명세라기보다, 화면 요청 URL과 폼 처리 URL을 함께 정리한 URL 설계서이다.

2차 개발에서 React로 전환할 경우, `/api` 경로를 사용하는 REST API 구조로 확장할 예정이다.

---

## 2. URL 설계 원칙

- 화면 조회는 `GET` 메서드를 사용한다.
- 데이터 등록 및 변경 처리는 `POST` 메서드를 사용한다.
- 일반 사용자 기능은 `/reports` 경로를 사용한다.
- 관리자 기능은 `/admin` 경로를 사용한다.
- 로그인하지 않은 사용자는 인증이 필요한 URL에 접근할 수 없다.
- 일반 사용자는 관리자 URL에 접근할 수 없다.

### 5-3. 처리상태 변경 기준

관리자는 별도의 상태 변경 URL을 사용하지 않고, 답변 등록/수정 또는 반려 처리 과정에서 처리상태를 변경한다.

#### 처리 방식
- 답변 등록 : `/admin/reports/{id}/answer`
- 답변 수정 : `/admin/reports/{id}/answer/edit`
- 반려 처리 : `/admin/reports/{id}/reject`

#### 허용 상태값

| 상태값         | 설명  |
|-------------|-----|
| RECEIVED    | 접수  |
| IN_PROGRESS | 처리중 |
| COMPLETED   | 완료  |
| REJECTED | 반려 |

#### 처리 내용
- 답변 내용을 저장한다.
- 선택한 처리상태를 저장한다.
- 답변한 관리자 ID를 저장한다.
- 답변일시를 저장한다.
- 수정일시를 갱신한다.

| 파라미터 | 타입 | 필수 | 설명 |
|---|---|---|---|
| answer | String | Y | 관리자 답변 내용 |
| status | String | Y | 처리상태 |

#### 처리 내용
- 답변 내용을 수정한다.
- 선택한 처리상태를 저장한다.
- 답변한 관리자 ID를 저장한다.
- 답변일시를 갱신한다.
- 수정일시를 갱신한다.

### 5-6. 오류신고 반려 처리

| 항목 | 내용 |
|---|---|
| Method | POST|
| URL | `/admin/reports/{id}/reject` |
| 설명 | 관리자가 답변이 없는 오류신고를 반려 처리한다. |
| 요청값 | `rejectReason` |

| 권한 | 관리자 |

#### 요청값

| 파라미터 | 타입 | 필수 | 설명 |

#### 처리 조건

- 반려 처리 시 처리상태를 `REJECTED`로 변경한다.
- 반려 사유를 저장한다.
- 처리 이력을 저장한다.

## 7. 2차 REST API 전환 예정

1차 개발에서는 Thymeleaf 기반 화면 렌더링과 폼 전송 방식으로 구현한다.

2차 개발에서 React로 전환할 경우, 아래와 같이 REST API 구조로 변경하는 것을 고려한다.

| 기능 | Method | URL |
|---|---|---|
| 회원가입 | POST | `/api/auth/signup` |
| 로그인 | POST | `/api/auth/login` |
| 내 오류신고 목록 조회 | GET | `/api/reports` |
| 오류신고 등록 | POST | `/api/reports` |
| 오류신고 상세 조회 | GET | `/api/reports/{id}` |
| 전체 오류신고 목록 조회 | GET | `/api/admin/reports` |
| 처리상태 변경 | PATCH | `/api/admin/reports/{id}/status` |
| 관리자 답변 등록 | POST | `/api/admin/reports/{id}/answer` |
| 관리자 답변 수정 | PATCH | `/api/admin/reports/{id}/answer` |
