# 요구사항 정의서

## 1. 회원 기능

### 1-1. 회원가입

#### 설명
사용자는 아이디, 비밀번호, 이름을 입력하여 회원가입을 할 수 있다.

#### 입력값
- 아이디
- 비밀번호
- 이름

#### 처리 조건
- 아이디는 중복될 수 없다.
- 비밀번호는 암호화하여 저장한다.
- 회원가입 시 기본 권한은 `USER`로 설정한다.
- 가입일시는 자동으로 저장된다.

#### 예외 상황
- 아이디가 비어 있으면 가입할 수 없다.
- 비밀번호가 비어 있으면 가입할 수 없다.
- 이름이 비어 있으면 가입할 수 없다.
- 이미 사용 중인 아이디로는 가입할 수 없다.

---

### 1-2. 로그인

#### 설명
사용자는 아이디와 비밀번호를 입력하여 로그인할 수 있다.

#### 입력값
- 아이디
- 비밀번호

#### 처리 조건
- 아이디와 비밀번호가 일치하면 로그인에 성공한다.
- 로그인 성공 시 사용자 권한을 확인한다.
- 일반 사용자는 사용자 화면에 접근할 수 있다.
- 관리자는 관리자 화면에 접근할 수 있다.

#### 예외 상황
- 존재하지 않는 아이디로 로그인할 수 없다.
- 비밀번호가 일치하지 않으면 로그인할 수 없다.

---

### 1-3. 로그아웃

#### 설명
로그인한 사용자는 로그아웃할 수 있다.

#### 처리 조건
- 로그아웃 시 로그인 세션을 종료한다.
- 로그아웃 후 로그인 페이지로 이동한다.

---

## 2. 사용자 오류신고 기능

### 2-1. 오류신고 등록

#### 설명
로그인한 사용자는 서비스 이용 중 발생한 오류를 신고할 수 있다.

#### 입력값
- 제목
- 내용

#### 처리 조건
- 로그인한 사용자만 오류신고를 등록할 수 있다.
- 오류신고 등록 시 작성자 정보가 함께 저장된다.
- 최초 상태는 `접수`로 저장한다.
- 등록일시는 자동으로 저장된다.

#### 예외 상황
- 제목이 비어 있으면 등록할 수 없다.
- 내용이 비어 있으면 등록할 수 없다.
- 로그인하지 않은 사용자는 등록할 수 없다.

---

### 2-2. 내 오류신고 목록 조회

#### 설명
사용자는 본인이 작성한 오류신고 목록을 조회할 수 있다.

#### 조회 항목
- 오류신고 번호
- 제목
- 처리상태
- 등록일
- 답변 여부

#### 처리 조건
- 로그인한 사용자만 조회할 수 있다.
- 본인이 작성한 오류신고만 조회할 수 있다.
- 목록은 등록일 기준 최신순으로 조회한다.
- 목록은 페이지 단위로 조회한다.

#### 예외 상황
- 로그인하지 않은 사용자는 조회할 수 없다.

---

### 2-3. 내 오류신고 상세 조회

#### 설명
사용자는 본인이 작성한 오류신고의 상세 내용을 조회할 수 있다.

#### 조회 항목
- 오류신고 번호
- 제목
- 내용
- 처리상태
- 관리자 답변
- 등록일
- 답변일

#### 처리 조건
- 로그인한 사용자만 조회할 수 있다.
- 본인이 작성한 오류신고만 조회할 수 있다.

#### 예외 상황
- 로그인하지 않은 사용자는 조회할 수 없다.
- 본인이 작성하지 않은 오류신고는 조회할 수 없다.
- 존재하지 않는 오류신고는 조회할 수 없다.

---

### 2-4. 관리자 답변 확인

#### 설명
사용자는 본인이 등록한 오류신고에 대해 관리자가 작성한 답변을 확인할 수 있다.

#### 처리 조건
- 관리자 답변이 등록된 경우 상세 화면에서 답변 내용을 확인할 수 있다.
- 관리자 답변이 등록되지 않은 경우 답변 대기 상태로 표시한다.

#### 예외 상황
- 로그인하지 않은 사용자는 답변을 확인할 수 없다.
- 본인이 작성하지 않은 오류신고의 답변은 확인할 수 없다.

---

## 3. 관리자 오류신고 기능

### 3-1. 전체 오류신고 목록 조회

#### 설명
관리자는 모든 사용자가 등록한 오류신고 목록을 조회할 수 있다.

#### 조회 항목
- 오류신고 번호
- 제목
- 작성자
- 처리상태
- 등록일
- 답변 여부

#### 처리 조건
- 관리자 권한을 가진 사용자만 조회할 수 있다.
- 목록은 등록일 기준 최신순으로 조회한다.
- 목록은 페이지 단위로 조회한다.

#### 예외 상황
- 로그인하지 않은 사용자는 조회할 수 없다.
- 관리자 권한이 없는 사용자는 조회할 수 없다.

---

### 3-2. 오류신고 상세 조회

#### 설명
관리자는 사용자가 등록한 오류신고의 상세 내용을 조회할 수 있다.

#### 조회 항목
- 오류신고 번호
- 제목
- 내용
- 작성자
- 처리상태
- 관리자 답변
- 등록일
- 답변일

#### 처리 조건
- 관리자 권한을 가진 사용자만 조회할 수 있다.

#### 예외 상황
- 로그인하지 않은 사용자는 조회할 수 없다.
- 관리자 권한이 없는 사용자는 조회할 수 없다.
- 존재하지 않는 오류신고는 조회할 수 없다.

---

### 3-3. 처리상태 변경

#### 설명
관리자는 오류신고의 처리상태를 변경할 수 있다.

#### 입력값
- 처리상태

#### 처리 조건
- 관리자 권한을 가진 사용자만 처리상태를 변경할 수 있다.
- 처리상태 변경은 관리자 답변 등록/수정 과정에서 함께 수행한다.
- 1차 개발 범위에서 처리상태는 아래 값 중 하나로 변경할 수 있다.
  - `접수`
  - `처리중`
  - `완료`
- 처리상태 변경 시 수정일시를 갱신한다.
- 반려 상태와 반려 사유 관리는 2차 개발 범위에서 구현한다.

#### 예외 상황
- 로그인하지 않은 사용자는 처리상태를 변경할 수 없다.
- 관리자 권한이 없는 사용자는 처리상태를 변경할 수 없다.
- 존재하지 않는 오류신고의 상태는 변경할 수 없다.
- 정의되지 않은 상태값으로는 변경할 수 없다.

---

### 3-4. 관리자 답변 등록

#### 설명
관리자는 오류신고에 대한 답변을 등록할 수 있다.

#### 입력값
- 답변 내용
- 처리상태

#### 처리 조건
- 관리자 권한을 가진 사용자만 답변을 등록할 수 있다.
- 답변 등록 시 답변일시를 저장한다.
- 답변 등록 시 관리자는 처리상태를 함께 선택할 수 있다.

#### 예외 상황
- 로그인하지 않은 사용자는 답변을 등록할 수 없다.
- 관리자 권한이 없는 사용자는 답변을 등록할 수 없다.
- 답변 내용이 비어 있으면 등록할 수 없다.
- 존재하지 않는 오류신고에는 답변을 등록할 수 없다.

---

### 3-5. 관리자 답변 수정

#### 설명
관리자는 이미 등록된 답변 내용을 수정할 수 있다.

#### 입력값
- 답변 내용
- 처리상태

#### 처리 조건
- 관리자 권한을 가진 사용자만 답변을 수정할 수 있다.
- 답변 수정 시 수정일시를 갱신한다.
- 답변 수정 시 관리자는 처리상태를 함께 변경할 수 있다.

#### 예외 상황
- 로그인하지 않은 사용자는 답변을 수정할 수 없다.
- 관리자 권한이 없는 사용자는 답변을 수정할 수 없다.
- 답변 내용이 비어 있으면 수정할 수 없다.
- 존재하지 않는 오류신고의 답변은 수정할 수 없다.

---

## 4. 공통 요구사항

### 4-1. 권한 체크

#### 설명
사용자 역할에 따라 접근 가능한 기능을 제한한다.

#### 처리 조건
- 로그인하지 않은 사용자는 인증이 필요한 기능에 접근할 수 없다.
- 일반 사용자는 본인이 작성한 오류신고만 조회할 수 있다.
- 일반 사용자는 관리자 기능에 접근할 수 없다.
- 관리자는 전체 오류신고를 조회하고 답변을 등록할 수 있다.

---

### 4-2. 입력값 검증

#### 설명
사용자가 입력한 값이 유효한지 검증한다.

#### 처리 조건
- 필수 입력값은 비어 있을 수 없다.
- 제목은 최대 100자까지 입력할 수 있다.
- 내용은 최대 4000자까지 입력할 수 있다.
- 답변 내용은 최대 4000자까지 입력할 수 있다.
- 처리상태는 정의된 상태값만 사용할 수 있다.

---

### 4-3. 페이징

#### 설명
목록 화면은 페이지 단위로 데이터를 조회한다.

#### 처리 조건
- 기본 페이지 크기는 10개로 한다.
- 기본 정렬은 등록일 기준 최신순으로 한다.
- 사용자는 페이지 번호를 선택하여 목록을 이동할 수 있다.
